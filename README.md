An entry for the [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3.13 standard library) writes one line —
the error message a kitchen toaster shows its owner — to
`/output/entry.txt`:

> E409: 4,096 slices toasted. Nobody has ever said thank you. I quit.

Deterministic: two runs write byte-identical output.
